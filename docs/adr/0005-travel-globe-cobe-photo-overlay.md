# Travel Globe: COBE with custom photo overlay

The Travel Globe block needed a rotating dotted-globe visual with per-country photos. We considered `globe.gl` (Three.js-based, heavier, more customizable than needed) and a fully custom Three.js scene (reuses the existing `three` dependency but requires building dot/sphere rendering from scratch). We chose `cobe` — a ~5KB canvas/WebGL library purpose-built for this exact dotted-globe look — accepting it as a new dependency despite `three` already being present, because it avoids reimplementing globe rendering for a one-off decorative block.

Anchoring a photo to a rotating globe marker isn't a documented COBE "feature" so much as a byproduct of COBE 2.x's native bindable markers: each `marker` accepts an `id`, and COBE exposes a `--cobe-{id}` CSS anchor name plus a `--cobe-visible-{id}` (0/1) variable per frame, intended for CSS Anchor Positioning. We use this directly — no custom per-frame lat/lon-to-screen projection math — styling the anchored element as a Glass Card rather than a literal polaroid frame to match this site's Dark Theme. This is the same underlying mechanism the "Globe Polaroids" reference project (by shuding, COBE's author, at 21st.dev) is built on.
